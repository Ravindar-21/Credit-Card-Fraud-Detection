# Credit Card Fraud Detection

This project demonstrates a credit card fraud detection workflow using machine learning on a real-world transaction dataset.

## Overview

The notebook in this repository explores:

- Data loading and exploration
- Feature analysis and class distribution
- Data preprocessing and scaling
- Model training and evaluation
- Fraud detection performance metrics

## Files

- `Credit_Card_Fraud_Detection.ipynb` – main Jupyter notebook containing the analysis and model workflow
- `creditcard.csv/creditcard.csv` – dataset used for training and evaluation

## Requirements

Install the required Python packages before running the notebook:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

## Run the notebook

```bash
jupyter notebook
```

Then open `Credit_Card_Fraud_Detection.ipynb` in the browser and run the cells.

## Notes

This is a learning/demo project focused on identifying fraudulent transactions using classification techniques.
